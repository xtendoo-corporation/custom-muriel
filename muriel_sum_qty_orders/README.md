# muriel_sum_qty_orders

Módulo para Odoo que añade un botón de acción masiva en la vista de lista de pedidos de venta.

## Qué hace

- Muestra un botón en la lista de pedidos cuando hay registros seleccionados.
- Genera un PDF con:
  - número de pedidos seleccionados,
  - número de líneas de producto,
  - suma total de cantidades,
  - detalle por pedido.

## Dependencias

- `sale`
